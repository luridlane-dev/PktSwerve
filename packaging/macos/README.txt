PktSwerve for macOS
===================

Easiest way: install from Terminal

  curl -fsSL https://raw.githubusercontent.com/luridlane-dev/PktSwerve/main/packaging/macos/install.sh | bash

The script downloads the latest build and installs it without any macOS
security warning.

Installing from this disk image

  1. Right-click "Install PktSwerve.command", choose Open, then Open again.
  2. If macOS still refuses, go to System Settings > Privacy & Security,
     scroll down and click "Open Anyway".

PktSwerve runs in the menu bar. Click its icon and press Start. macOS asks
for your password once, to set up the network rules.
